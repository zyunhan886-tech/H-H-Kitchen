# 我家菜谱（微信小程序）

全家共享的菜谱 + 冰箱。一个人添加、修改，家里其他人那边会同步。

- **菜谱**：首页列出全部菜，右下角 ＋ 添加。每道菜分三块：**食材**（emoji 图标）→ **备菜** → **炒菜**
- **冰箱**：直接写"芹菜一斤，鸡蛋10个、酱油一瓶"，识别后确认放进冰箱；点一下能改数量或标记"用完了"
- **详情页**会标出哪些食材冰箱里已经有（绿色 ✓）
- **家庭**：创建后会生成 6 位邀请码，点"发给家人"，对方打开卡片就能加入

## 第一次跑起来

1. **注册小程序**：打开 https://mp.weixin.qq.com → 立即注册 → 小程序 → 主体类型选"个人"。
   注册后在 开发管理 → 开发设置 里复制 **AppID**。
2. **安装微信开发者工具**（稳定版）：https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html
3. **导入项目**：开发者工具 → 导入 → 目录选这个文件夹 → 填你的 AppID（不要用"测试号"，测试号用不了云开发）。
   也可以直接把 `project.config.json` 里的 `touristappid` 换成你的 AppID。
4. **开通云开发**：工具栏点"云开发" → 开通，创建一个环境（会提示选套餐，按官网当前价格）。
   如果你有多个环境，把 `miniprogram/app.js` 顶部的 `CLOUD_ENV` 填成环境 ID。
5. **部署云函数**：左侧文件树里右键 `cloudfunctions/api` → **上传并部署：云端安装依赖**。
   第一次调用会自动建好 `families / members / dishes / fridge` 四个集合，不用手动建。
6. 点"编译"，切到"家庭"页 → 创建家庭 → 开始加菜。

## 给家人用（不用备案）

开发者工具点"上传" → 到 mp.weixin.qq.com 的 **版本管理** 把它设为**体验版** →
**成员管理 → 体验成员** 里加上家人的微信号。家人扫体验版二维码打开，在"家庭"页输入邀请码，
或者直接点你分享的邀请卡片。

## 想公开发布

1. 小程序后台 → **小程序备案**：填信息、实名、人脸核验，等管局审核（一般 1–3 周）
2. 备案通过 → 版本管理里提交审核 → 审核通过 → 发布

## 代码结构

```
cloudfunctions/api/index.js   唯一的云函数，所有读写都在这里，按家庭隔离、校验权限
miniprogram/
  pages/index    菜谱列表 + ＋ 按钮
  pages/detail   菜品详情（食材 / 备菜 / 炒菜）
  pages/edit     添加 / 修改 / 删除菜品
  pages/fridge   冰箱：文字录入 + 一眼看到有什么
  pages/family   创建 / 加入 / 邀请 / 退出家庭
  pages/join     邀请卡片的落地页
  utils/parse.js 冰箱文字识别（芹菜一斤、半斤五花肉、鸡蛋，10个…）
  utils/emoji.js 按食材名自动配 emoji，想加词改这里
  utils/const.js 菜品分类，想改分类改这里
```

数据库只允许云函数读写（客户端不直接访问集合），所以集合权限保持默认"仅创建者可读写"即可。
